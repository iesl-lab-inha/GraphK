# Dataset features

This directory is a placeholder for the precomputed dataset features required by `run1.py`. The actual feature files were not supplied with the source code or experiment records and are not included.

| Dataset argument | Required file |
|---|---|
| `IEMOCAP` | `iemocap_multi_features.pkl` |
| `MELD` | `meld_multi_features.pkl` |


Place the corresponding feature file here before running the training commands. Obtain the data from an authorized source and follow the dataset's access and redistribution terms. Load only trusted pickle files. The `.pk` files in `results/` are experiment outputs and cannot replace these feature files.
